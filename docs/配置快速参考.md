# 配置快速参考 ⚡

## 🎯 修改IP和端口（最常用）

**文件位置**: `lib/constant/app_config_env.dart`

```dart
/// 开发环境配置
factory ServerConfig.development() => const ServerConfig(
  host: '120.46.85.43',  // ← 修改IP地址
  httpPort: 80,          // ← HTTP接口端口
  wsPort: 80,            // ← WebSocket端口（可以不同）
  useHttps: false,
  // ... 其他配置
);
```

**注意**: HTTP和WebSocket可以使用不同的端口！

修改后**无需**重启IDE，只需重新运行应用即可！

## 🔄 切换环境

### 方式1：代码中切换（推荐）
文件：`lib/constant/app_config.dart`
```dart
static const AppEnvironment environment = AppEnvironment.development; // 或 testing, production
```

### 方式2：编译时切换
```bash
# 开发环境
flutter run --dart-define=ENVIRONMENT=development

# 生产环境
flutter build apk --dart-define=ENVIRONMENT=production
```

