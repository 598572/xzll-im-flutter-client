# 配置管理系统使用指南

## 概述

我们已经为项目创建了一个统一的配置管理系统，解决了IP、端口和API URL分散管理的问题。现在所有的服务器配置都集中在一个地方，支持多环境配置。

## 文件结构

```
lib/constant/
├── app_config.dart          # 主配置文件，提供统一的配置接口
├── app_config_env.dart      # 环境配置文件，支持多环境
└── config_demo.dart         # 配置使用演示（可删除）
```

## 主要特性

### 1. 统一配置管理
- ✅ 所有IP、端口配置集中管理
- ✅ 所有API URL统一生成
- ✅ WebSocket URL自动生成
- ✅ 超时时间等参数可配置

### 2. 多环境支持
- 🔧 开发环境 (development)
- 🧪 测试环境 (testing) 
- 🚀 生产环境 (production)

### 3. 灵活的环境切换
- 代码中修改默认环境
- 编译时通过参数指定环境

## 使用方法

### 修改IP和端口

编辑 `lib/constant/app_config_env.dart` 文件：

```dart
/// 开发环境配置
factory ServerConfig.development() => const ServerConfig(
  host: '120.46.85.43',  // 修改这里的IP
  port: 80,              // 修改这里的端口
  useHttps: false,
  enableDebugLog: true,
  connectionTimeout: 30,
  receiveTimeout: 30,
  webSocketRetryCount: 5,
);
```

### 切换环境

#### 方法1：修改默认环境
在 `lib/constant/app_config.dart` 中修改：
```dart
static const AppEnvironment environment = AppEnvironment.production; // 改为生产环境
```

#### 方法2：编译时指定环境
```bash
# 开发环境
flutter run --dart-define=ENVIRONMENT=development

# 测试环境  
flutter run --dart-define=ENVIRONMENT=testing

# 生产环境
flutter build apk --dart-define=ENVIRONMENT=production
```

### 在代码中使用配置

```dart
import 'package:xzll_im_flutter_client/constant/app_config.dart';

// 获取基础URL
String baseUrl = AppConfig.baseUrl;

// 获取WebSocket URL
String wsUrl = AppConfig.getWebSocketUrl(userId);

// 获取API端点
String loginUrl = AppConfig.loginUrl;
String friendListUrl = AppConfig.friendListUrl;

// 获取配置参数
int timeout = AppConfig.connectionTimeout;
int retryCount = AppConfig.webSocketRetryCount;
```

## 添加新环境

如需添加新环境，请按以下步骤：

1. 在 `AppEnvironment` 枚举中添加新环境：
```dart
enum AppEnvironment {
  development('开发环境'),
  testing('测试环境'), 
  production('生产环境'),
  staging('预发布环境'),  // 新增
}
```

2. 在 `ServerConfig` 中添加对应的工厂方法：
```dart
factory ServerConfig.staging() => const ServerConfig(
  host: 'staging.example.com',
  port: 443,
  useHttps: true,
  // ... 其他配置
);
```

3. 在 `AppConfigEnv.serverConfig` 中添加对应的case：
```dart
case AppEnvironment.staging:
  return ServerConfig.staging();
```

## 迁移指南

如果你有其他文件使用了硬编码的URL，请按以下方式迁移：

### 替换硬编码URL
```dart
// 旧方式 ❌
final url = 'http://120.46.85.43:80/api/user/search';

// 新方式 ✅  
final url = '${AppConfig.baseUrl}/api/user/search';
// 或者如果已经定义了对应的API端点
final url = AppConfig.searchUserUrl;
```

### 替换WebSocket URL
```dart
// 旧方式 ❌
final wsUrl = 'ws://120.46.85.43:80/websocket?userId=$userId';

// 新方式 ✅
final wsUrl = AppConfig.getWebSocketUrl(userId);
```

## 常见问题

### Q: 如何快速切换到测试服务器？
A: 使用编译参数：`flutter run --dart-define=ENVIRONMENT=testing`

### Q: 如何添加新的API端点？
A: 在 `AppConfig` 类中添加新的getter方法：
```dart
static String get newApiUrl => '$baseUrl/new/api/endpoint';
```

### Q: 如何临时修改某个环境的配置？
A: 直接修改 `app_config_env.dart` 中对应环境的工厂方法即可。

- 📱 支持开发、测试、生产多环境
- ⚡ 通过编译参数快速切换环境
- 🛠️ 统一管理超时、重连等参数

不再需要在多个文件中查找和修改IP地址了！
